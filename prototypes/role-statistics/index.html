Статистика по ролям

Локальная демонстрация. Здесь только тестовые действия и тестовые роли. Данные сбрасываются при закрытии сервера. Защита реальных пользователей не подключена.

Выберите роль

Выберите роль, чтобы открыть статистику.

Добавить тестовое действие

Кнопки имитируют действия одного тестового пользователя для одного тестового места.

Поделиться = нажатие кнопки, не подтверждение отправки. Числа показывают количество действий, а не уникальных людей или текущее число лайков.
