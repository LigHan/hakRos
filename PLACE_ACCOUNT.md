# Т-06. Кабинет заведения

Войдите в аккаунт компании и откройте **Профиль → Управлять заведениями**. Здесь можно создать карточку или изменить уже привязанное заведение. В карточке редактируются название, адрес, описание, категория, ссылка на фото и часы работы. Для расписания можно добавить несколько периодов, например «Пн–Пт» и «Сб–Вс».

После сохранения нажмите «Открыть карточку», чтобы проверить публичный вид. Новый аккаунт компании получает своё первое заведение при создании карточки. В локальном деморежиме тестовой компании уже привязан парк Щербакова.

## API

Маршруты используют токен компании из `POST /login`. При создании владелец берётся из серверной сессии. Кабинет и статистика используют существующие связи из `local_place_owners`.

| Метод и путь | Результат |
|---|---|
| `GET /api/company/places` | Карточки текущей компании |
| `GET /api/company/places/:placeId` | Своя карточка |
| `POST /api/company/places` | Создать и привязать карточку |
| `PUT /api/company/places/:placeId` | Сохранить свою карточку |

Поля формы — `place`, `address`, `bio`, `category`, `image` и `workingHours`. У часов работы форма `[{ label, value }]`. Пустой массив очищает расписание. Пустая ссылка на фото показывает заглушку, а пропущенное поле `image` при редактировании сохраняет текущее фото. При повторной отправке создания интерфейс использует тот же `requestId`, поэтому повторный запрос возвращает ту же карточку.

Публичный маршрут `GET /api/posts/:id` возвращает сохранённые данные. Запуск проверки из `backend` — `node --test company-places.local.test.js`.
