# Зависимости и установка

Приложение перенесено из [LigHan/paths, коммит e1f4863](https://github.com/LigHan/paths/tree/e1f4863be60abbace48c0c98c806e86bb17ff43c). Исходная связка Expo 54, React 19.1 и React Native 0.81 заменена совместимыми версиями для Expo SDK 58. Старые `.env` и SQLite-файл остались в исходной копии. База нового проекта создаётся из схемы и демонстрационных данных в `backend/db.js` и `backend/seed.js`.

## Проверенные версии

| Участок | Пакеты |
|---|---|
| Среда | Node.js 24.22.2, npm 11.19.1, Windows |
| Интерфейс | Expo 58.0.23, Expo Router 58.0.30, React и React DOM 19.3.0 |
| Платформы | React Native 0.88.1, React Native Web 0.21.4, WebView 14.0.1 |
| Проверки | TypeScript 6.0.3, ESLint 9.39.5, eslint-config-expo 58.0.4 |
| Сервер | Express 5.3.0, sqlite3 6.0.1, bcrypt 6.0.0, dotenv 18.0.10, cors 2.8.6 |
| Режим разработки API | nodemon 3.1.14 |

Версии всех прямых и транзитивных зависимостей зафиксированы в `frontend/package-lock.json` и `backend/package-lock.json`. Используйте `npm ci` отдельно в каждой папке. `npm run dev` в `backend` запускает сервер с перезагрузкой при правках.

## Как обновлять

- Для Expo и связанных пакетов используйте версии из установленного SDK. После изменения выполните `npm exec -- expo install --check` и проверьте lint, типы и экспорт. [Матрица совместимости Expo](https://docs.expo.dev/versions/v58.0.0/)
- ESLint остаётся на ветке 9, которую поддерживают плагины конфигурации Expo. Переход на новый major делайте после обновления их диапазонов совместимости.
- При обновлении серверных зависимостей проверьте запуск с чистой SQLite-базой и с существующей базой. Сверьте ответы маршрутов мест, историй и аккаунтов.
- Пункт 5 согласует обновления общих манифестов и lock-файлов. Команды запуска и переменные окружения описаны в [README.md](README.md).
